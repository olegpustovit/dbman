v2 makes the DB browser the agent’s safe hands. Claude Code, Codex, Cursor and seven more platforms reach your databases only through DBMan’s MCP server. Agents never write to a database: they read, and write only into their own layer of the DBMan store (row patches, virtual views, relations, notes, dashboards); only a human adopts or applies to the database. Passwords never leave DBMan’s Keychain, sensitive columns are hidden by default, production sits behind an EXPLAIN guard, and every call is visible in the app. Plus: composable dashboards, a schema map and the first app icon.
